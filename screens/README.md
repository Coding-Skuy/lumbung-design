# Layar Lumbung

## Aplikasi Lapangan (`lapangan-mobile`)

- Daftar lot — kartu ringkas per lot aktif.
- Detail lot — panen, asal kebun, status trip.
- Catat trip — formulir berangkat/tiba.

## Aplikasi Gudang (`gudang-desktop`)

- Antrean timbang — daftar lot menunggu timbang.
- Layar timbang — angka timbangan besar + tombol simpan.
- Pratinjau struk fee — tata letak struk thermal 58mm.

## Web Ops (`lumbung-web`)

- Ops — rekap lot, timbangan, fee harian.
- Rute — daftar trip dan statusnya.
- Papan harga — tabel harga pasar induk.
