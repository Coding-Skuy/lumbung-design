# Token Desain Lumbung

Token dasar (nama kebab-case, nilai awal).

## Warna

- `--lumbung-hijau-daun: #2E7D32` — aksi utama gudang.
- `--lumbung-kuning-panen: #F9A825` — sorotan lot aktif.
- `--lumbung-abu-karung: #616161` — teks sekunder.
- `--lumbung-merah-susut: #C62828` — peringatan susut berlebih.
- `--lumbung-putih-kapas: #FAFAFA` — latar utama.

## Tipografi

- Judul: 20/28 tebal; Isi: 14/20 reguler; Struk: monospace 12.

## Radius dan Spasi

- Radius kartu: 12; tombol: 8. Skala spasi: 4, 8, 12, 16, 24.
